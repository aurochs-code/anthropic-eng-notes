# 分镜：ppo-clip（PPO 截断目标）

## 基本信息

- **所属笔记**：`papers/p-29-ppo.md`
- **插入位置**：`## 关键公式或机制` → `### 1. 截断替代目标`，放在“优势为负（坏动作）……”这条列表之后、`### 2. 另一种做法：自适应 KL 惩罚` 之前。
- **组件类型**：函数曲线 + 滑块（试点里用来打通整条管线）。
- **一句话机制**：PPO 对单个样本取 min(r·Â, clip(r, 1−ε, 1+ε)·Â)；只在“继续改会让目标变好”的方向上把概率比 r 截在 1±ε 处，往变差的方向不截断。
- **形式**：滑块为主（ε 滑块 + 可拖动的 r 点 + 优势正负切换），附 4 步分步说明。

## 分步说明（4 步，每步一句；配合高亮）

1. **起点**：r = 1 表示新旧策略对这个动作给出同样的概率，三条线在这里重合（读数：Â=+1 时三项都是 1.00）。
2. **好动作往上推**（Â = +1，把点拖到 r = 1.5）：未截断项继续涨到 1.50，截断项停在 1.20，取较小值得 1.20。超过 1+ε 以后目标不再增加，梯度为 0，所以不会一步把这个动作的概率拉得太高。
3. **好动作往下掉**（Â = +1，拖到 r = 0.5）：未截断项是 0.50，截断项是 0.80，取较小值得 0.50。这一侧不截断，目标变差会被如实计入，梯度照常把 r 往回拉。
4. **坏动作对称地反过来**（切到 Â = −1）：r 低于 1−ε 时目标停在 −0.80 不再变好（例如 r = 0.5：−0.50 与 −0.80 取较小值 −0.80）；r 高于 1+ε 时继续变差（例如 r = 1.5：−1.50 与 −1.20 取较小值 −1.50）。概括：**只截断“会让目标变好”的那一侧**，所以 L^CLIP 是未截断目标的一个下界（悲观估计）。

以上读数均为 ε = 0.2 时按公式计算，大厨实现后可以用来做快照测试。
