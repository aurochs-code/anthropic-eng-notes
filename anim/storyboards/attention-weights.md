# 分镜：attention-weights（缩放点积注意力的权重计算）

## 基本信息

- **所属笔记**：`papers/p-13-attention-is-all-you-need.md`
- **插入位置**：`## 关键公式或机制` → `### 1. 缩放点积注意力（scaled dot-product attention）`，放在“论文也解释了为什么选点积……”这一段之后、`### 2. 多头` 之前。
- **组件类型**：分步播放器 + SVG 场景 + 点选。
- **一句话机制**：每个词用自己的查询 q 和所有词的键 k 做点积，除以 √d_k，经 softmax 变成一组和为 1 的权重，再用这组权重对所有词的值 v 求加权和，得到这个词的新表示。
- **形式**：分步（6 步）为主，第 6 步起可以点选任意一个词作为查询；附一个“去掉 ÷√d_k”的对比开关。

## 原创示意数据

### 例句和取值依据

- 例句：**「小狗 / 追 / 皮球」**，3 个 token。选它是因为“追”这个动词自然地同时关联主语和宾语，便于说明一个词会从多个词“取信息”。例句为笔者自拟，**不要**换成网上常见图解里的英文例句。
- 维度：d_k = 4（查询、键的维度），d_v = 2（值的维度）。选 d_v = 2 是为了能把值向量和加权结果直接画在一个二维小坐标系里。
- 数值是手工挑的小整数，目的是让每一步都能心算，**不是**任何训练好的模型的参数。设计意图：让“追”对“皮球”的权重最高、对“小狗”次之。

| token | 查询 q（d_k=4） | 键 k（d_k=4） | 值 v（d_v=2） |
|---|---|---|---|
| 小狗 | [1, 0, 1, 0] | [2, 0, 1, 0] | [1, 0] |
| 追 | [1, 1, 0, 1] | [0, 1, 0, 0] | [0, 1] |
| 皮球 | [0, 1, 0, 0] | [0, 2, 0, 1] | [1, 1] |

### 每一步的计算结果（笔者用 numpy 复算过，显示三位小数）

点积 Q·Kᵀ（行 = 查询，列 = 键）：

| | 小狗 | 追 | 皮球 |
|---|---|---|---|
| 小狗 | 3 | 0 | 0 |
| 追 | 2 | 1 | 3 |
| 皮球 | 0 | 1 | 2 |

除以 √d_k = √4 = 2：

| | 小狗 | 追 | 皮球 |
|---|---|---|---|
| 小狗 | 1.5 | 0 | 0 |
| 追 | 1.0 | 0.5 | 1.5 |
| 皮球 | 0 | 0.5 | 1.0 |

按行 softmax 后的注意力权重：

| | 小狗 | 追 | 皮球 |
|---|---|---|---|
| 小狗 | 0.691 | 0.154 | 0.154 |
| 追 | 0.307 | 0.186 | 0.506 |
| 皮球 | 0.186 | 0.307 | 0.506 |

加权求和后的输出（d_v = 2）：小狗 → [0.846, 0.309]；追 → [0.814, 0.693]；皮球 → [0.693, 0.814]。

对比开关（**不**除以 √d_k，直接 softmax）：小狗 [0.909, 0.045, 0.045]；追 [0.245, 0.090, 0.665]；皮球 [0.090, 0.245, 0.665]。权重明显更“尖”。

三位小数显示时，每行之和可能是 0.999，需在图上注明“四舍五入”。

## 画面构成（原创设计）

- 顶部一行 3 个 token 卡片：小狗、追、皮球。当前查询词的卡片用 `--accent` 描边。
- 中部左侧：当前查询的 q 向量，以及三个键向量 k 竖排，每个旁边写点积结果；中部右侧是一个 3×3 的权重网格，**只用一种强调色的深浅**表示大小（深 = 大），每个格子里写数值。不要做成彩虹色热力图，也不要画成常见图解里那种从一个词向另一个词拉出粗细不同连线的样式。
- 底部：二维小坐标系（0–1.2），画三个值向量 v 的点（小狗 (1,0)、追 (0,1)、皮球 (1,1)），加权和用一个空心点表示，从原点出发的虚线指向它；空心点必然落在三个点围成的三角形内，用来直观说明“加权平均”。
- 角落固定标注“示意数据（手工设定，非训练所得）”。

## 分步说明（6 步）

1. **每个词有三个向量**：查询 q（“我在找什么”）、键 k（“我能被怎样找到”）、值 v（“被选中时交出的内容”）。在真实模型里它们由输入向量分别乘以三组可学习的矩阵得到；这里直接给出示意数值。
2. **打分：查询和每个键做点积**。以「追」为查询：与「小狗」点积 2、与「追」点积 1、与「皮球」点积 3。
3. **缩放：除以 √d_k**。这里 d_k = 4，所以除以 2，得到 1.0、0.5、1.5。论文的理由是：d_k 大时点积数值会很大，softmax 会被推到梯度极小的区域。
4. **softmax 变成权重**：0.307、0.186、0.506，三者之和为 1。「追」对「皮球」关注最多，对「小狗」次之。
5. **加权求和**：0.307 × [1, 0] + 0.186 × [0, 1] + 0.506 × [1, 1] = [0.814, 0.693]。这就是「追」这一层的输出，落在三个值向量围成的三角形里。
6. **每个词都做一遍**：三行权重拼起来就是 3×3 的注意力矩阵，一次矩阵乘法 softmax(Q·Kᵀ / √d_k)·V 就能同时算完。此时可以点选任意一个词作为查询（读者交互）。

**对比开关**（第 3 步之后可用）：关掉缩放后「追」这一行变成 0.245、0.090、0.665。说明文字：“不缩放时分布更尖。这个小例子里 d_k 只有 4，差别还不算大；论文里每个头的 d_k 是 64，点积的方差会随 d_k 增大，不缩放时 softmax 更容易饱和。”

## 已核对的公式和数字

| 内容 | 出处 | 核对结果 |
|---|---|---|
| Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k)·V | 论文第 3.2.1 节 Scaled Dot-Product Attention，第 4 页，公式 (1) | 一致 |
| 查询与所有键点积、各除以 √d_k、softmax 得到值上的权重 | 第 3.2.1 节，第 4 页 | 一致 |
| d_k 大时点积数值变大，把 softmax 推到梯度极小的区域，因此按 1/√d_k 缩放 | 第 4 页第 3.2.1 节末段及脚注 4（q、k 各分量独立、均值 0 方差 1 时，点积均值 0、方差 d_k） | 一致 |
| d_k 小时点积与加性注意力表现相近，d_k 大时不缩放的点积不如加性 | 第 4 页第 3.2.1 节 | 一致 |
| h = 8 个头，d_k = d_v = d_model / h = 64 | 第 3.2.2 节 Multi-Head Attention，第 5 页 | 一致 |
| 示意数据各步结果 | 笔者用 numpy 复算 | 已复算 |
